# FileShare v0.3.0

## 변경 사항

- 모바일 업로드를 2MiB 메모리 조각 전송으로 변경. 선택한 파일 입력은 묶음 전송 완료까지 유지합니다.
- 일시적인 연결 끊김·응답 유실 시 서버 저장 위치를 확인하여 자동 이어 올리기. 연속 최대 12회 재시도, 일시정지 버튼은 그대로 지원합니다.
- 다중 선택 후 전송 목록으로 즉시 이동하고, 파일 목록·썸네일 갱신은 묶음 완료 후 한 번 수행합니다.
- PC 설정에 Windows 로그인 시 자동 시작 옵션 추가. INI 저장 및 현재 사용자 자동 시작 등록/해제.
- 비밀번호 최소 길이를 4자로 변경(최대 128자).

Windows는 EXE를 실행하고 트레이에서 설정을 엽니다. 기존 서버를 먼저 종료하고 실행 파일을 교체하세요. 기존 FileShare.ini와 data 폴더를 유지하면 설정과 미완료 전송을 계속 사용합니다. 자동 시작을 켠 경우 EXE 경로가 유지되어야 합니다.

## 검증과 한계

Go 테스트·vet, HTTP/전송 복구 테스트 13개 통과. 실제 64MiB 업로드에 약 10MiB 간격의 실패와 응답 유실을 주입하여 자동 완료 및 SHA-256 일치를 확인했습니다. Windows 자동 시작 등록/해제는 실제 레지스트리 API로 격리된 테스트 키에서 검증했습니다. 실제 재부팅 검증은 하지 않았습니다.

Safari 사진 선택창의 변환·iCloud 다운로드 대기는 웹페이지가 강제로 없앨 수 없습니다. 파일이 웹페이지에 전달된 뒤의 흐름을 개선했습니다. 실물 iPhone에서 이번 수정본을 검증하지는 못했습니다. 선택기 ‘현재’ 형식 또는 파일 앱 원본 사용을 권장합니다. https://bugs.webkit.org/show_bug.cgi?id=325067

Windows x64/ARM64 EXE·ZIP, macOS ARM64/x64, 소스 ZIP, 체크섬 및 검증 보고서를 제공합니다. 포함된 21GiB 전송 기록은 이전 버전 전송 엔진 검증 결과입니다.
